# -Simple-AI-Map-Model-of-Yemeni-Cities
 Simple AI Map Model of Yemeni Cities
 ​وصف المشروع:
​اسم المشروع: محاكي المسارات الذكي - خارطة اليمن
النوع: تطبيق تفاعلي لمحاكاة خوارزميات الذكاء الاصطناعي (AI) في اختيار الطرق، مصمم لتبسيط مفاهيم الملاحة والبحث عن أفضل المسارات.
الوظيفة الأساسية: يساعد النظام المستخدم على إيجاد أقصر طريق بين المدن اليمنية بسرعة ودقة. يعتمد البرنامج على خوارزمية (A^*) التي تحاكي طريقة عمل أنظمة الخرائط العالمية (مثل Google Maps). كما يوفر ميزة تفاعلية تسمح بوضع "عقبات" أو قطع طرق معينة، ليقوم البرنامج فوراً بالبحث عن مسار بديل وتحديث النتائج، مما يجعله أداة تعليمية وعملية لفهم كيفية إدارة حركة المرور وتجنب الطرق المزدحمة أو المغلقة.
